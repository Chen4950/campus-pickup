# 校园快递驿站取件助手

单站课程原型。系统提供多件货架路线、逐件查找进度、截图识别以及分时排队预测与错峰推荐。默认载入 5 件示例包裹。驿站、包裹和排队观测均为合成数据。

## Windows 本地运行

在本目录打开 PowerShell。首次安装使用 `./start.ps1 -Install`。依赖已经安装时使用 `./start.ps1`，然后打开 [本地取件助手](http://127.0.0.1:8000)。按 Ctrl+C 停止服务。端口被占用时可用 `./start.ps1 -Port 8001`。

本项目在 Node 24 与 Python 3.14 上验证。Vue 3 由 Vite 构建，FastAPI 同时提供网页与 API。SQLite 在首次运行时从 `backend/data/demo.json` 导入样本，并在数据源内容改变后更新数据。

## 取件演示

1. 打开取件路线，查看 5 件包裹对应的 4 次货架停靠。以同货架只停一次的通知顺序对比，样例路线由 95 米降为 35 米。
2. 在 A1 确认两件包裹已找到。在 A2 把剩余的一件标为暂未找到。系统以 A2 为新起点，重新规划途经 C2、C1、核验点和出口的 24 米路线。刷新页面后检查清单与当前位置。
3. 添加包裹时可手填，或使用截图识别。可用 `tests/fixtures/notice-demo.png` 演示。截图裁剪后由 RapidOCR 和 ONNX Runtime 在本机识别。用户确认货架后，识别结果加入同一张清单。取件码无法定位时需要手动确认货架。
4. 打开错峰计划，选择日期和可到站时间。系统比较半小时粒度的时段。存在待取包裹时按入口出发的路线估算到核验处的时间，再查询对应时段的队列。

## 验证

运行 `./.venv/Scripts/python.exe -m unittest discover -s tests -v` 检查路线、排队窗口、OCR 字段解析和示例图片的实际推理结果。服务启动后，可访问 [接口文档](http://127.0.0.1:8000/docs) 或 [预测回测结果](http://127.0.0.1:8000/api/forecasts/evaluation)。

队列回测以前 21 天为训练样本，以后 7 天为留出样本。等待时间来自模拟观测，步行和找件使用界面列出的演示参数。实际误差和路线节省量需要在试点驿站进行采集和走测。
